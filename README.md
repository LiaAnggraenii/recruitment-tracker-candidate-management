# Recruitment Tracker & Candidate Management

## Project Overview

This project is an Excel-based recruitment tracking and candidate management system designed to organize recruitment data, monitor application progress, and provide insights into recruitment activities through an interactive dashboard.

The project uses structured datasets and Excel features to transform raw recruitment data into an organized tracking system and visual summary.

## Objectives

- Organize applicant, company, job, and application data.
- Track candidate applications and their current recruitment stages.
- Analyze application sources and job positions.
- Provide a centralized recruitment overview through an Excel dashboard.

## Tools & Techniques

- **Microsoft Excel**
- Excel Tables
- Lookup Functions (`INDEX`, `MATCH`)
- Conditional Aggregation (`COUNTIF`, `COUNTA`)
- PivotTables
- PivotCharts
- Data Formatting and Dashboard Design

## Workbook Structure

| Worksheet | Description |
|---|---|
| Applicants | Contains applicant information. |
| Companies | Contains company information. |
| Jobs | Contains job vacancy information. |
| Applications | Contains candidate application records. |
| Application_Stages | Contains recruitment stage records. |
| Application_Tracker | Combines application information into a centralized tracking table. |
| Recruitment_Summary | Provides recruitment KPIs, analysis, and visualizations. |

## Dashboard Features

The Recruitment Summary dashboard includes:

- **Recruitment KPIs:** Total Applications, Total Applicants, Total Jobs, and Total Companies.
- **Application Progress:** Overview of completed, in-progress, and not-started applications.
- **Recruitment Source Analysis:** Application distribution by recruitment source.
- **Job Application Analysis:** Application counts by job title and company.
- **Top 10 Job Positions:** Visualization of job positions with the highest number of applications.

## Dataset

The project uses a synthetic recruitment dataset from the *Job Board Applications & Interviews* dataset.

The dataset is licensed under **CC0 1.0 (Public Domain Dedication)**.

The workbook is intended for learning and portfolio demonstration purposes.

## Key Learning Outcomes

- Building a centralized application tracking system.
- Summarizing data using PivotTables.
- Creating charts and KPI-based dashboards.
